# Mapa de destinos do site ICGE (www.icge.org.br)

Gerado em 2026-10-19 a partir da REST API do WordPress (`/?rest_route=/wp/v2/pages`; o caminho `/wp-json/` e os sitemaps retornam 404/406) + menu da home. 
Total: **573 páginas publicadas**, **180 marcadas como úteis**. 363 delas são itens individuais do Quiz (testes dos livros de Waldo Vieira), acessíveis pelo hub 2297.

Notas técnicas: muitas páginas são “tabelas pesquisáveis” carregadas via JavaScript (Google Charts + Google Sheets) ou painéis embutidos (Power BI, Looker Studio, Google Apps Script). O texto estático delas é curto, mas a página é funcional. `M` = página presente no menu principal.
